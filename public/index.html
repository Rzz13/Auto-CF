Cara Kerja & Panduan Email Routing

1. Konfigurasi Cloudflare Email Routing

  1. Buka dashboard Cloudflare, pilih domain Anda yang akan digunakan.
  2. Masuk ke menu Email -> Email Routing lalu aktifkan fiturnya.
  3. Buat Destination Address baru dan verifikasi alamat email tujuan tersebut.
  4. Di tab Routing Rules, buat rule baru (misalnya Catch-All atau custom address) dengan aksi Send to Worker dan arahkan ke worker yang baru dideploy (cloudflare-email-handler).

2. KV Namespace & Worker Mailer

Worker menggunakan Cloudflare KV Namespace bernama EMAIL_KV untuk menyimpan sementara isi email yang diterima selama 1 jam. Saat otomatisasi signup berjalan, program akan melakukan request HTTP fetch ke Worker URL dengan menyertakan parameter ?email=nama@domain.com untuk membaca isi email.

3. Membuat KV Namespace Secara Manual

  1. Di dashboard Cloudflare, buka menu Workers & Pages -> KV.
  2. Klik tombol Create Namespace.
  3. Beri nama namespace baru Anda: EMAIL_KV.
  4. Setelah dibuat, salin ID Namespace yang dihasilkan (32 karakter hex).
  5. Tambahkan binding KV berikut ke berkas wrangler.toml Anda jika setup manual:
    [[kv_namespaces]] binding = "EMAIL_KV" id = "ID_NAMESPACE_ANDA"

4. Mengamankan Worker dengan X-API-Key (Opsional)

Untuk membatasi akses ke Worker agar hanya dashboard otomatisasi ini yang bisa membaca kotak masuk email kustom Anda:

  1. Buka Dashboard Cloudflare, buka Worker Anda -> masuk ke tab Settings -> Variables.
  2. Di bagian Environment Variables, klik Add Variable.
  3. Masukkan nama key: API_KEY (atau X_API_KEY) dan isi nilainya dengan token rahasia buatan Anda sendiri.
  4. Klik Save and Deploy.
  5. Di tabel **Pengelola Domain Email** pada dashboard ini, isi kolom **API Key** dengan token rahasia yang sama saat mendaftarkan domain. Sistem otomatis mengirimkan header x-api-key saat mengambil verifikasi email.
